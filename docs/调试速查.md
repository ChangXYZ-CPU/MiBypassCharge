## 关键路径

| 项 | 路径 |
|---|---|
| 模块目录 | `/data/adb/modules/bypass_guard` |
| 运行时数据 | `/data/adb/bypass_guard` |

```bash
adb shell su
M=/data/adb/modules/bypass_guard
D=/data/adb/bypass_guard
```

## 状态与控制

```bash
sh $M/bin/bg-ctl.sh status      # LEVEL/STATUS/CUR/POWER/BP/MODE/BACKEND/TS
sh $M/bin/bg-ctl.sh get         # 当前配置
sh $M/bin/bg-ctl.sh on          # 强制旁路
sh $M/bin/bg-ctl.sh resume      # 恢复充电 + 回到自动（通知栏按钮用这个）
sh $M/bin/bg-ctl.sh off         # 强制充电（MODE=force_off，不会自动回来）
sh $M/bin/bg-ctl.sh auto        # 交回自动
sh $M/bin/bg-ctl.sh toggle
sh $M/bin/bg-ctl.sh restart
sh $M/bin/bg-ctl.sh log 60
sh $M/bin/bg-ctl.sh set THRESHOLD_ON 80
```

## 手工验证旁路（只看电流，不看 status）

```bash
Q=/sys/class/qcom-battery
B=/sys/class/power_supply/battery

cat $B/current_now          # 负=充电，正=放电/停充
cat $B/status               # 旁路中可能是 Charging（滞后，别信）

# 按当前电量停充
LV=$(cat $B/capacity)
printf '0x%x\n' $(( (LV << 16) | 3 )) > $Q/smart_chg
sleep 5; cat $B/current_now                    # 应≈0
cat /sys/class/power_supply/usb/voltage_now    # 应仍在 9V 左右

# 解除（必须两步）
echo 0x2 > $Q/smart_chg; sleep 8
echo 0   > $Q/smart_chg; sleep 10
cat $B/current_now                             # 应回到 -3A 以下
```

| 现象 | 结论 |
|---|---|
| `current` ≈ 0，VBUS 还在 9V | 真旁路 ✔ |
| `current` 变正数（+0.4A）、VBUS 掉到 5V | 这是 `input_suspend` 的断充，手机在吃电池 ✘ |
| `current` 没变、还是 -4A | 掩码没生效（电量低位写错 / 节点被别的东西接管） |

## 排错对照

| 症状 | 先查 |
|---|---|
| 到阈值不停 | `cat $B/current_now` 是否≈0；`cat $Q/smart_chg` 是否为 2 |
| 停了又回充 | `log` 里有没有 `reassert`；节点是不是被别的 App 改了 |
| 恢复充电慢 | 正常，PD 重协商要 10–20 s |
| 通知不出现 | `bg-ctl.sh app`；打开一次 App 解除 stopped |
| 卸载后不充电 | `echo 0x2 > $Q/smart_chg; sleep 8; echo 0 > $Q/smart_chg` |

## 卸载

KernelSU 移除模块即可。`uninstall.sh` 会两步复位 `smart_chg`、复位 `input_suspend`、
撤通知、卸 App。配置目录保留，彻底清理 `rm -rf /data/adb/bypass_guard`。
